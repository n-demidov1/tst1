# Замер скорости интернета (netspeed)

Консольный скрипт: делает несколько **последовательных** запросов к одному адресу
(например, к тяжёлой картинке), дожидается полного ответа на каждый и печатает:

- время каждого запроса;
- среднее время запроса;
- общий объём скачанных данных;
- итоговую скорость скачивания.

Нужен только Python 3.9+ — сторонних зависимостей нет.

## Запуск

Из корня проекта:

```bash
python -m netspeed https://example.com/big-image.jpg
```

Параметры:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `url` | — | http(s)-адрес файла, обязательный |
| `-n`, `--count` | `10` | число последовательных запросов |
| `-t`, `--timeout` | `30` | таймаут одного запроса, секунды |

Пример:

```bash
python -m netspeed "https://downloader.disk.yandex.ru/preview/95b30f8ca1579fe5b48fbddeb608642c085f831cc5459bf6644b4b979cb636c1/6afb34fc/qIXoc3N2Z8fglz2parGVy298w43VAA76E_y7HD7RNqvidlFaru5Uuu4fxdsbeH2Q7BQRbGTpcoRhiiEc3eH5ug%3D%3D?uid=0&filename=bfoto_ru_4761.jpg&disposition=inline&hash=&limit=0&content_type=image%2Fjpeg&owner_uid=0&tknv=v3&is_direct_zip_experiment=1&size=2048x2048" -n 5 -t 60
```

Пример вывода:

```text
Замер скорости: https://example.com/big-image.jpg
Запросов: 10, последовательно

  запрос  1:    5.120 МБ за   0.512 с  (   80.00 Мбит/с)
  ...

Среднее время запроса:  0.498 с
Всего скачано:          51.20 МБ (51200000 байт)
Скорость скачивания:    82.25 Мбит/с
```

Можно установить как команду `netspeed`:

```bash
pip install -e .
netspeed https://example.com/big-image.jpg
```

## Единицы измерения

| Величина | Единица | Пояснение |
|---|---|---|
| Скорость | **Мбит/с** (мегабиты в секунду) | 1 Мбит = 1 000 000 бит. Так скорость указывают провайдеры и Speedtest-подобные сервисы |
| Объём | **МБ** (мегабайты) и байты | 1 МБ = 1 000 000 байт (десятичный, не МиБ) |
| Время | **секунды** | |

Формула: `скорость = (суммарные байты × 8) / суммарное время всех запросов / 1 000 000`.

Чтобы перевести в МБ/с (как показывают браузеры при загрузке), разделите Мбит/с на 8.

## Что именно измеряется

- Время запроса — от начала соединения (DNS, TCP, TLS) до последнего байта тела ответа.
  Поэтому на маленьких файлах результат сильно занижен задержкой (ping), а не
  пропускной способностью. Берите файл от 5–10 МБ и больше.
- Каждый запрос открывает новое соединение.
- Скрипт просит не отдавать данные из кэша (`Cache-Control: no-cache`) и без сжатия
  (`Accept-Encoding: identity`), но сервер/CDN может это проигнорировать.
- Измеряется скорость до конкретного сервера, а не «скорость интернета вообще».

## Коды выхода

| Код | Значение |
|---|---|
| 0 | успех |
| 2 | ошибка сети или HTTP (4xx/5xx), неверные аргументы |
| 3 | сервер вернул пустой ответ |
| 130 | прервано Ctrl+C |

## Тесты

Тесты поднимают локальный HTTP-сервер и не ходят в интернет:

```bash
python -m unittest discover -s tests -t . -v
```

## Структура

```text
netspeed/
  core.py      — запросы, тайминги, расчёт (без печати)
  cli.py       — разбор аргументов и вывод
  __main__.py  — точка входа для `python -m netspeed`
tests/
  test_netspeed.py
```
